# 🛰️ Attack Path

> [!ABSTRACT] Overview of Common Attack Vectors & Enumeration Techniques
>
> This document outlines typical attack paths and enumeration techniques used to compromise systems through various protocols, focusing on initial access vectors like SMB and HTTP.

---

## 🌐 Web Application Security Testing

### Initial Reconnaissance

```bash
nmap -sC -sV <target-IP>
```

> [!NOTE]
> This command uses NSE scripts for default service enumeration to gather information about the web application environment.

### Vulnerability Scanning

```text
wpscan --url https://<target-url>/ --enumerate u
```
> [!INFO] 
> WPScan is used here to scan for WordPress-specific vulnerabilities and enumerate user roles, plugins, themes, etc.

---

## 🛰️ SMB (Server Message Block)

### Quick Enumeration Workflow

```text
445 Open?
   ↓
Enumerate Shares
   ↓
Check Null/Guest Access
   ↓
Enumerate Users/Groups
   ↓
Look for Sensitive Files
   ↓
Password Spray
   ↓
Admin Access?
   ↓
PsExec / SMBExec / PtH
```

---

## 📂 Important SMB Shares

| Share | Purpose |
|---|---|
| `C$` | Entire C Drive |
| `ADMIN$` | Windows Directory |
| `IPC$` | RPC Communication |
| `NETLOGON` | Domain Logon Scripts |
| `SYSVOL` | Domain Policies |

## 🔍 Initial Enumeration

### Nmap

```bash
sudo nmap -sC -sV -p139,445 <IP>
```

Aggressive SMB Enumeration:

```bash
sudo nmap --script smb* -p445 <IP>
```

> [!SUCCESS]
> The above commands provide a thorough enumeration of the target's SMB services.

## HTTP/HTTPS

### Web Application Fingerprinting

```text
curl -I https://<target-url>/wp-login.php
```
> [!CHECK] 
> This command helps identify whether a WordPress login page exists and gathers version information.

### Directory Traversal

```bash
dirb http://<target-url>
```

> [!WARNING]
> Ensure you have permission to test the target application as directory traversal can lead to unauthorized data access.

## 📌 High-Value Files to Hunt

SMB:

```text
passwords.txt
creds.txt
backup.zip
KeePass (.kdbx)
web.config
groups.xml
id_rsa
config.php
database.yml
.vpn
```

HTTP/HTTPS:

```text
/admin/
/index.php?debug=true
/config.php
/.git/
```

Also search for keywords: `password`, `passwd`, `secret`, `token`, `key`, `credential`, `backup`.

## 🧭 Attack Path Mental Model

```text
Identify Open Ports and Services → 
  SMB/HTTP Presence? →
    Enumerate Shares or Web Folders →
      Look for Sensitive Files →
        Exploit Vulnerabilities (e.g., Password Spraying, SQL Injection) →
          Gain Admin Access →
            Lateral Movement via Pass-the-Hash or HTTP Sessions
```

> [!SUCCESS] 
> Following this mental model provides a systematic approach to identifying and exploiting common attack vectors in both SMB and web-based environments.

## 📝 Additional Notes

### Tools & Techniques

#### CrackMapExec

Local Accounts:

```bash
crackmapexec smb <IP> \
-u users.txt \
-p 'Password123!' \
--local-auth
```

Domain Accounts:

```bash
crackmapexec smb <IP> \
-u users.txt \
-p 'Password123!'
```
> [!NOTE]
> CrackMapExec is a powerful tool for SMB enumeration and credential attacks.

#### WPScan

Vulnerability Scanning:

```text
wpscan --url https://<target-url>/ --enumerate u
```

> [!INFO] 
> WPScan can be used to assess the security posture of WordPress installations by identifying potential vulnerabilities and misconfigurations.
