## 🔎 Initial Network Scan

### Nmap Port Scanning

```bash
nmap -sS -p- <target_ip>
```

Identified open ports include 22, 80, and 443.

---

## 📂 Directory Enumeration

### Web Root Search

Used `dirb` to find sensitive directories on web servers:

```bash
dirb http://<ip>/ /usr/share/wordlists/dirb/common.txt -r
```

Identified hidden directories such as `/admin`, `/wp-admin`, and `/config`.

## 🔑 Password Cracking Attempts

### Hashcat Attack on Shadow File

```bash
hashcat -m 1000 hashes.txt wordlist.txt
```
Identified weak passwords for users `admin` and `guest`.

---

## 📄 Sensitive Data Extraction

### Database SQL Injection

Exploited a vulnerable web application to extract database credentials:

```sql
SELECT * FROM users WHERE username='admin' AND password IN (SELECT password FROM admin_passwords);
```

Extracted usernames, passwords, and hashes.
