## 📈 Web Application Scanning

### Nmap and Nikto Usage

Use [[Nmap]] to perform network scans, followed by [[Nikto]] for web application scanning.

#### Example Usage

Network Scan:

```bash
sudo nmap -sS -T4 example.com
```

Web App Scan:

```bash
nikto -h http://example.com:80
```

## 🗄 Data Storage and Analysis

### Storing Collected Information

Store the collected OSINT data in a structured format for analysis.

#### Example SQLite Database Schema

```sql
CREATE TABLE osint_data (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    source TEXT NOT NULL,
    content TEXT,
    date_collected DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

## ⚠️ Common Pitfalls and Best Practices

### Avoiding Oversights

Common pitfalls to avoid during OSINT data collection include:

- Missing important data sources.
- Failing to maintain anonymity.
- Overlooking legal and ethical boundaries.

#### Best Practices

1. Always respect privacy laws and guidelines.
2. Use multiple tools for redundancy.
3. Maintain thorough documentation of processes and findings.
