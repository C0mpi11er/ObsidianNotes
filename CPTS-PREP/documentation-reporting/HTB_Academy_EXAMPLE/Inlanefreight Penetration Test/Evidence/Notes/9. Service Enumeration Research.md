# 🛰️ Service Enumeration Research

> [!ABSTRACT] Overview of Service Enumeration
> This document covers the process of identifying and assessing open services on a target system, focusing on common enumeration techniques for various protocols like SMB, SSH, HTTP, etc.

---

## 🔍 Initial Steps

### Nmap Basic Scan

```bash
nmap -sT <IP>
```

### Advanced Service Enumeration

Use [[Nmap]] with specific scripts to gather more information:

```bash
nmap --script smb-os-discovery,smb-enum-shares,nmap-broadcast-dns \
-p139,445,<other_ports> <IP>
```

---

## 🛰️ SMB (Server Message Block)

### Port Detection

```text
sudo nmap -p139,445 --script=smb-os-discovery <IP>
```

### Enumerate Shares

Use [[CrackMapExec]] for detailed enumeration:

```bash
crackmapexec smb <IP> --shares
```

---

## 🔐 SSH (Secure Shell)

### Initial Detection

Basic port scan to detect open ports:

```text
nmap -p22,143,993 <IP>
```

### Version Gathering

Use [[Nmap]] for version detection:

```bash
sudo nmap -sV -p22 <IP>
```

---

## 🌐 HTTP (Hypertext Transfer Protocol)

### Basic Scan

Initial scan to find open ports and services:

```text
nmap -p80,443 --script=http-enum <IP>
```

### Web Application Discovery

Use [[Nikto]] for web application scanning:

```bash
nikto -h http://<IP>:80
```

---

## 🔍 Initial Enumeration Workflow

1. Identify Open Services:
   ```text
   nmap -p- <IP>
   ```
2. Focus on Specific Ports:
   ```text
   nmap -p139,445,22,80,443 <IP>
   ```
3. Detailed Service Enumeration:
   ```bash
   sudo nmap --script smb* -p139,445 <IP>
   ```

## 📂 Important Findings

### SMB Shares

| Share | Purpose |
|---|---|
| `C$` | Entire C Drive |
| `ADMIN$` | Windows Directory |
| `IPC$` | RPC Communication |

### SSH Users

- Enumerate users:
  ```text
  ssh -l user <IP>
  ```
- Check authorized_keys:
  ```bash
  cat ~/.ssh/authorized_keys
  ```

## 🔐 Vulnerability Assessment

### SMB Misconfigurations

Check for null session access:

```bash
smbclient -N -L //<IP>
```

Evaluate SMB signing requirements:

```text
[!WARNING] Ensure SMB Signing is enabled.
```

## ⚠️ Common Issues

### Null Session Access

| Finding | Impact |
|---|---|
| Null Session Accessible | User Enumeration |

Evaluate for potential exploitation:

```text
[!CHECK] Use [[CrackMapExec]] to check null session access.
```

### Weak Credentials

- Identify weak credentials through password spraying:
  ```bash
  crackmapexec smb <IP> \
    -u users.txt \
    -p 'Password123!'
  ```
