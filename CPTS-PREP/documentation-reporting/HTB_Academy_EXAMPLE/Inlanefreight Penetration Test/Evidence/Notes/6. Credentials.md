# 🔑 Credentials

> [!ABSTRACT] What are Credentials?
>
>Credentials encompass usernames, passwords, API keys, session tokens, and other information used to authenticate and authorize access in a network environment.

---

## 🚦 Authentication Mechanisms

### Kerberos & NTLM
Kerberos is the primary authentication protocol for Windows environments, while NTLM (NT LAN Manager) serves as a fallback mechanism. Both protocols are critical for understanding credential management within Active Directory domains.

> [!INFO] Key Concepts
>
>- **Kerberos**: Utilizes tickets to authenticate users.
>- **NTLM**: A challenge-response protocol used when Kerberos is not available.

### LM & NTLMv1/2 Hashes

- **LM (LAN Manager) Hash**: An older, weak hashing algorithm no longer recommended for use.
- **NTLMv1 and NTLMv2**: Successor algorithms to LM with improved security features. NTLMv2 is the stronger of the two.

## 🔍 Enumerating Credentials
Credential enumeration involves identifying potential accounts and passwords within a target environment.

### Common Tools

#### CrackMapExec (CME)
Used for credential dumping, pass-the-hash attacks, and more.

```bash
crackmapexec smb <IP> -u users.txt -p 'Password123!' --local-auth
```

---

## 🚀 Credential Harvesting Techniques
Various techniques can be employed to gather credentials from a target system or network.

### Pass-the-Hash (PtH)

Pass-the-hash involves using stolen NTLM hashes without needing the original password. This method is particularly useful for lateral movement and privilege escalation within an AD environment.

```bash
crackmapexec smb <IP> -u Administrator -H NTHASH --ptt ticket.txt
```

### Kerberoasting

Kerberoasting attacks involve requesting service tickets from a domain controller using the Kerberos protocol, then cracking these tickets to retrieve NTLM hashes.

```bash
kerbrute userenum -d DOMAIN.COM users.txt
```

## 🔑 Storing and Protecting Credentials
Storing credentials securely is crucial for preventing unauthorized access. Common methods include:

- **Password Vaults**: Tools like KeePass or LastPass.
- **Encrypted Storage**: Using tools such as GPG to encrypt sensitive data.

> [!WARNING] Security Best Practices
>
>- Never store plain-text passwords on disk unless absolutely necessary.
>- Use multi-factor authentication (MFA) wherever possible.

---

## 🚦 Credential Attacks and Defenses

### Common Attack Vectors

- **Brute Forcing**: Automated attacks to guess credentials through repeated login attempts.
- **SMB Relays**: Leveraging SMB signing weaknesses to perform NTLM relaying.

#### Mitigation Strategies

- **Strong Password Policies**: Implementing complex password requirements and regular changes.
- **Account Lockout Policies**: Temporarily locking accounts after multiple failed login attempts.

---

## 🧠 Mental Model: Credential Management
Understanding the lifecycle of credentials is vital for both offensive and defensive cybersecurity operations. It encompasses creation, usage, storage, and disposal phases to ensure robust security practices are in place.

> [!SUCCESS] Key Takeaway
>
>- **Credentials Are Critical**: Proper management of credentials can prevent unauthorized access and reduce the risk of data breaches.
>- **Regular Audits**: Regularly auditing credential systems helps identify weaknesses before they can be exploited.
