# 🛰️ Kerbrute Enumeration Techniques

[!NOTE] Use this mode to reduce chances of detection by limiting requests per second.

```bash

```

[!INFO] Use higher thread counts to speed up the process, but be cautious of getting blocked by network security measures.


[!WARNING] This can bypass some detection mechanisms but may leave traces in logs.


## ⚙ Automated Username Generation
[!NOTE] Use tools like `Username Anarchy` or custom scripts to generate a comprehensive list of usernames.

```bash
# Using Username Anarchy
git clone https://github.com/urbanadventurer/username-anarchy.git
echo "John Smith" | ./username-anarchy/username-anarchy > generated_users.txt

# Custom Script for Pattern Generation
cat > generate_users.sh << 'EOF'
#!/bin/bash
first="$1"
last="$2"
echo "${first,,}.${last,,}"        # john.smith
echo "${first:0:1}${last,,}"       # jsmith
echo "${first,,}${last,,}"         # johnsmith
echo "${last,,}.${first:0:1}"      # smith.j
echo "${last,,}${first:0:1}"       # smithj
EOF

chmod +x generate_users.sh
./generate_users.sh John Smith
```

# 🔍 Event Log Analysis for Detection

## ⚙ Windows Event IDs Generated by Kerberos Attacks
[!WARNING] Monitor these event IDs to detect Kerberos attacks.

```bash
# Event ID 4768 - Kerberos TGT Request (Username enumeration)
# Event ID 4771 - Kerberos pre-authentication failed (Password attacks)

Get-WinEvent -LogName Security | Where-Object {$_.Id -eq 4768} | Select-Object TimeCreated,Message
```

# 🛡️ Defense and Detection

## ⚙ Monitoring for Rapid 4768 Events from Single IP
[!INFO] PowerShell script to detect rapid Kerberos TGT requests.

```bash
Get-WinEvent -LogName Security | Where-Object {
    $_.Id -eq 4768 -and $_.TimeCreated -gt (Get-Date).AddMinutes(-5)
} | Group-Object {$_.Properties[6].Value} | Where-Object Count -gt 10
```

## ⚙ Mitigation Strategies
[!SUCCESS] Implement these strategies to reduce the risk of successful attacks.

- **Account lockout policies** - But affects legitimate users.
- **Rate limiting** - Throttle authentication requests.
- **Network monitoring** - Detect unusual Kerberos traffic.
- **Honey accounts** - Fake accounts to detect enumeration.
